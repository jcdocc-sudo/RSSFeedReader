If you want to test the API directly, you can also call the backend from a terminal:
 $ Invoke-RestMethod -Uri "http://localhost:5052/api/subscriptions" -Method Get

And add a subscription:
 $ $body = @{ url = "https://example.com/feed.xml" } | ConvertTo-Json
Invoke-RestMethod -Uri "http://localhost:5052/api/subscriptions" -Method Post -ContentType "application/json" -Body $body
